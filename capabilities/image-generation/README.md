# 图片生成：agent 自带生图服务

## 适用场景

需要情境插画、角色、背景或其他视觉素材时使用。趣味化讲解可以使用彩色插画和角色；专业化讲解按需使用简洁的辅助图片。是否生图由讲解内容决定，不要求每页配图。

## 调用入口

使用当前 agent 环境自带的生图服务，遵循该环境提供的工具与技能说明。本仓库不绑定具体供应商、模型名、API 参数或额外服务配置。先确认环境是否提供该能力；没有时可采用文字、基础图形等方式，核心体验受影响时再与用户确认调整。

## 输入与输出

- 输入：教学用途、已确认风格、需要表现的对象与关系、构图和尺寸要求；需要保持一致的角色或参考图。
- 输出：供 slide 使用的图片素材，保留素材与对应页面的关系，便于修改或替换。素材如何嵌入最终课件在制作阶段决定。

## 使用边界

生图适合提供视觉素材，不承担精确几何约束、公式排版和数学证明。关键文字、数字与公式优先由正文或相应工具呈现，图中内容须核对。动态讲解的顺序与交互由课件组织，图片本身不等于动态演示。

## 按需读取

制作时发现并读取当前 agent 自带生图工具的说明；只有选中该能力后才加载其详细调用要求。不同环境的调用差异保留在这一层，不改变总体讲解规划流程。
