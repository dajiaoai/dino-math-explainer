# 能力注册表

agent 在第一轮规划前读取本表，结合当前环境提供的工具确认可用能力，据此规划呈现方式；用户确认总体方案后，为各 slide 选用能力，再读取对应详细说明。能力注册不代表当前环境一定已安装或可用。

| ID | 能力 | 适用场景 | 工具来源 | 说明 |
| --- | --- | --- | --- | --- |
| `algeo-sdk` | 几何演示 | 题干或推理中的几何主图（含固定图形、标注和分步高亮）、精确构造、函数图像、对象联动 | 大角几何 SDK | [接入与文档](algeo-sdk/README.md) |
| `image-generation` | 图片生成 | 情境插画、角色、背景、视觉素材 | 当前 agent 自带生图服务 | [使用与边界](image-generation/README.md) |
| `sound-effects` | 课件音效 | 判题反馈、按钮操作、重点揭示、限时活动、关键操作 | 本地音频与生成脚本 | [音频文件与调用方式](sound-effects/README.md) |

同一页可组合多种能力。几何主图默认用 SDK，示意数轴、分类树和集合圈可直接用 HTML/CSS/SVG。选型规则见 [SKILL.md](../SKILL.md#约束)。

## 注册新的能力

1. 使用稳定 ID，建立 `<能力 ID>/` 目录，以 `README.md` 为入口，相关参考文档放在该能力目录内。
2. 在上表登记用途、工具来源和文档链接。
3. 在能力说明中写清以下信息：

| 字段 | 内容 |
| --- | --- |
| 适用场景 | 能帮助解释什么，何时值得使用 |
| 调用入口 | SDK、agent 内置工具或其他实际入口；如何确认可用 |
| 输入 | agent 调用前需准备的内容、数据或素材 |
| 输出 | 返回什么，如何供 slide 使用或后续修改 |
| 使用边界 | 不适合承担的任务、运行限制及需要实际验证的行为 |
| 详细说明 | 按需读取的 API、语法、示例或制作文档 |

工具更换或升级时优先维护对应能力说明。总体讲解流程只依赖能力的用途，不写死具体工具的参数和调用顺序。
