# 数学动态讲解视觉设计

以课堂投影为主要场景。学生应能快速找到这一刻要看的对象，教师能在观察、提问、揭示和解释之间停顿。按已确认的风格选择题目的切入方式、配色和动效，按教学用途选择版式。

## 从参考中提取的设计原则

- **用连续变化解释数学。** 保留学生已经认识的坐标系、图形或符号，用变形、移动、描线或局部高亮说明「什么变了，什么保持」。例如变形时保留淡化的原网格作参照，随后把图中对象与公式对应项联系起来。 [3Blue1Brown《线性变换与矩阵》](https://www.3blue1brown.com/lessons/linear-transformations/)
- **让讲解对象占据舞台。** 用尺度、对齐和留白集中注意力。需要看图时给图形足够空间，需要读结论时让公式本身成为主视觉。把屏幕标题写成当前要观察的关系或问题，使教师可以直接指着屏幕讲。 [Apple Event 演示](https://www.youtube.com/watch?v=f1J38FlDKxo)
- **从适合内容的版式起步。** 实现共享页边距、对齐线和组件间距，让内容变化时由容器重排。同类页面沿用相同的版式规则。 [Beautiful.ai Smart Slides](https://www.beautiful.ai/smart-slides)

## 两种讲解风格

| 设计维度 | 专业化讲解 · 严谨克制 | 趣味化讲解 · 彩色 |
| --- | --- | --- |
| 切入问题 | 从条件、图形关系或关键等式切入，标题指向当前推理 | 从可观察的情境、猜想或动作切入，标题邀请学生预测 |
| 色彩与标注 | 用中性色承托画面，少量强调色标记已知条件、辅助线或当前推导 | 用鲜明色区分拼块、类别或可操作对象，同一颜色沿用同一含义 |
| 动效与操作 | 按推理顺序画辅助线、对齐等式、逐步揭示依据 | 用拼合、拆分、拖拽等有数学含义的动作，先留猜想时间，再展示结果 |

例如讲三角形面积，两种风格都可以演示两个全等三角形拼成平行四边形。严谨版沿着同一组底和高逐步标出拼合前后的关系与面积等式。趣味版用两种颜色追踪拼片，先停在「会拼成什么？」再播放拼合，并在图旁揭示面积关系。

## 版式与交互

为每个揭示步骤选一个视觉焦点，安排观察对象、屏幕文字、变化和停顿。把标签、公式或滑块放在对应对象附近。同一图形或符号跨步骤保留颜色与标记，重要区别同时用标签、线型或形状表达。预留连续推导需要的空间，让已有图形和等号在揭示时尽量保持位置。用统一的文字层级、对齐和间距组织画面，屏幕文字服务于观察、推理或操作。

| 版式起点 | 适用场景 |
| --- | --- |
| 主图 | 观察、变换或参数探索。图形占主要面积，问题和参数靠近图形。 |
| 图＋推导 | 需要来回对照图形与推理。公式和依据按讲解顺序出现，与对应图元联动强调。 |
| 双图对照 | 比较前后、两种解法或正反例。可直接比较的图尽量使用相同尺度，并对齐观察基准。 |
| 单公式 | 阅读结论或聚焦一次代数变化。多行推导按等号或逻辑关系对齐。 |

拖拽、点击选项和操作滑块时，让反馈出现在相关对象上，由教师另行推进揭示。提问页停在问题上，答案等教师推进后再出现。回退后核对显示内容与所在步骤是否一致。

## 屏幕适配与预览

- 以 16:9 全屏投影为默认场景，按目标设备确定画布设计尺寸。课堂演示时，按可用宽度与设计宽度之比、可用高度与设计高度之比中的较小值，等比缩放整张画布。窗口尺寸或全屏状态变化时更新倍率，保留当前步骤和交互状态。
- 题干、标题、正文、公式、图片、几何图元、字号、线宽、点大小、坐标轴和标签、间距及页内控件都使用同一画布倍率。固定的设计单位（如 CSS `px`）可用在统一缩放的画布内部。HTML、SVG、Canvas 和 SDK 画板可共用一个缩放父层，同时按缩放后的尺寸给画布留出空间。教学内容中的浮层和图形标注也要与对应对象一起缩放和定位。
- 播放器导航、全屏和静音等外部控件可独立布局，须可见、可操作并避开讲解内容。窄幅竖屏如需单独的阅读布局，可按讲解顺序重排或纵向滚动。切换布局后仍须让同一画布内的内容共享倍率，保留几何比例，并为标注和整个动画运动范围留出空间。
- 将同一页停在同一揭示步骤，在较小窗口和 16:9 全屏之间放大、缩小并恢复，核对文字和公式的大小、同一线段的显示长度、线宽、点大小及标签偏移是否随画布以同一比例变化。复查首屏、最密集的揭示步骤及有拖拽或动画的步骤，检查裁切、碰撞和点击位置，在缩放后推进、回退并确认交互状态。按目标设备补查窄幅竖屏。
